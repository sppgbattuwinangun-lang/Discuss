# Undangan Makan Romantis

Halaman undangan makan siang yang romantis, lucu, dan penuh animasi untuk calon pacar.

## Fitur
- Amplop pembuka yang bisa dibuka dengan klik (dengan animasi flap)
- Hujan emoji hati yang terus berjatuhan di background
- Judul dengan efek typing dan teks pelangi
- Kartu detail acara dengan glassmorphism
- Tombol "Mau" yang berkilauan + confetti saat diklik
- Tombol "Gak mau" yang **kabur** ketika hover (lucu!)
- Modal konfirmasi yang muncul dengan animasi pop
- Musik latar romantis (Web Audio API, tanpa file mp3)
- Responsive untuk mobile

## Cara Menjalankan Lokal

Buka file `index.html` di browser. Tidak butuh build step.

```bash
# atau pakai server statis sederhana
python3 -m http.server 8080
# lalu buka http://localhost:8080/undangan-makan/
```

## Cara Deploy (GitHub Pages)

1. Push folder ini ke branch `main` (atau aktifkan Pages di branch lain).
2. Di repo settings → Pages → pilih branch & folder root.
3. URL akan tersedia di: `https://<user>.github.io/Discuss/undangan-makan/`
